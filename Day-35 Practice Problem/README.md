# Day-35 Practice Problem

This folder is reserved for extra DSA practice problems that are **not part of the Apna College DSA Sheet**.

Each additional problem will be organized in its own numbered folder:

```text
Day-35 Practice Problem/
├── 01 - Problem Name/
│   ├── Solution.cpp
│   └── README.md
├── 02 - Problem Name/
│   ├── Solution.cpp
│   └── README.md
└── ...
```

Each problem's README will include its platform, problem link, approach, and time and space complexity.
